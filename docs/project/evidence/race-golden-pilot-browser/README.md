# Race Golden Pilot browser evidence

Run `npm run test:browser:race` from the repository root to refresh this folder.

The suite opens the real app and records geometry for every Guided step at 360px, 390px, 768px and 1280px. The focused lab repair refreshes only the Experiment 3 instrumentation Reveal screenshots at 390px and 1280px; it also checks that a written prediction and observation restore after reload. This is local study progress, not execution or mastery verification.

`browser-report.json` records the command, viewport geometry and the screenshot paths. This is automated interaction/layout evidence only: it does not prove that a learner understood the lesson or ran the C# console lab.
