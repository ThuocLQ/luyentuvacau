# QuanNet — Roadmap to First Complete Chapter

> **Status:** APPROVED DELIVERY STRATEGY

This execution plan does not replace the canonical learning standard or dependency map.

## Phase 1 — Complete roadmap architecture

Finish Stage 2 reviews, global synthesis, proxy fairness, over-gating/root preservation and acyclic graph checks; materialize and seal only after real validation. The 17 tracks are a capability map, not sequential chapters; 137 Learning Units are teaching/evidence boundaries, not an ordered catalog. Starting units must follow dependency evidence and entry assessment, never an arbitrary Indexing-first rule.

## Phase 2 — Golden Pilot

Select a dependency-valid Learning Unit; research it and build one complete Vietnamese lesson under `docs/engineering-learning-standard.md`: concept origin, mechanism, worked example, observable evidence, visualization, Windows-friendly lab, debug/failure, trade-offs, transfer, explanation, recall and L1–L4 checks. Technical and English evidence remain independent. Run validation plus desktop/mobile checks and obtain real human learner feedback before refining the reusable pattern. Never fabricate Human Validated.

## Phase 3 — First complete chapter release

Package a coherent dependency-valid module, not a forced track or arbitrary unit count. Complete every included lesson, fair prerequisite/progression evidence, labs, quizzes, exercises, debug flows, navigation, persistence, accessibility and desktop/mobile checks. Version it and release only when the complete chapter is stable. A chapter creates no new canonical capability or Learning Unit identity.

## Phase 4 — Study and development in parallel

After chapter acceptance, the user studies and reports real learning evidence; Codex develops the next dependency-valid chapter separately and submits it for review. Published material remains stable except verified bugs or learning blockers. Do not wait for all 137 units before study begins.

## Release quality gates

- **Roadmap:** reviewed prerequisites, no unjustified whole-unit gate, preserved roots, acyclic external graph, canonical consistency/tests.
- **Golden Pilot:** credible explanation, observable mechanism, runnable lab/debug, source-map traceability, real human feedback.
- **First chapter:** all lessons accepted, supported labs, fair assessment/progression, no hidden prerequisites, executed content/UI/browser checks, stable version.
- **Parallel development:** published chapter stable by default; next chapter separate; feedback drives targeted changes; each release independently validated.
